# B0 Ridge 基线实验结果

## 1. 实验信息

- 分支：`baseline/b0-ridge`
- 代码提交：`e2fbf90`
- 模型：Ridge回归
- 预测基线：固定为`0`
- 随机种子：`42`
- ECG采样率：`500 Hz`
- 窗口长度：`10 s`
- 导联顺序：`I、II、III、aVR、aVL、aVF、V1～V6`
- 受试者划分：88名训练受试者 / 22名验证受试者
- PPG：未使用
- 加速度数据：未使用
- Baseline Head：未使用

## 2. 数据协议

训练集和验证集按照受试者进行划分。

B0模型使用严格同步的D12数据进行训练和诊断。在严格同步验证前，对重复验证窗口进行了删除。

- 严格同步验证窗口数：240
- 删除的重复验证窗口数：273
- 训练集与验证集重叠窗口数：0

弱配对跨设备验证结果作为实验协议输出予以保留，但输入信号和目标信号之间并非严格同步。因此，弱配对数据上的Pearson相关系数不能直接作为模型真实重建性能的评价结果。

## 3. 模型协议

本实验训练两个Ridge模型：

- Task1：导联I重建12导联ECG
- Task2：6个肢体导联重建12导联ECG

模型采用闭式解的流式Ridge回归。

模型输出恢复为原始微伏值（μV）。模型不使用来自目标信号的基线信息，预测基线固定为0。

## 4. 严格同步训练集内部拟合诊断

| 任务 | 指标 | 结果 |
|---|---|---:|
| Task1 | 去中心化平均Pearson r | 约0.482 |
| Task2 | 去中心化平均Pearson r | 0.759730 |
| Task2 | 去中心化V1～V6平均RMSE | 283.910488 μV |

以上结果属于训练集拟合诊断，不是正式验证结果。
