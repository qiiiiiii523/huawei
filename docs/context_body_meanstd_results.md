# B5 体脂秤 mean+std context 编码器试验（2026-10-15）

## 设计

本轮在 `context_body` 分支以固定原始 B5 EMA 初始化，只替换体脂秤 context 编码器的跨窗口汇总：逐窗口 masked CNN / 投影保持不变，将按有效采样点加权的窗口特征均值与标准差送入小型融合层。B5 主干、原 FiLM 注入方式和零初始化保持不变；仅训练编码器与 FiLM，共 173,856 个参数。独立输出目录为 `results/context_body/A_frozen_meanstd_v1/`，不覆盖旧实验。

沿用 `A_frozen_adapter_v1` 协议：体脂秤 `A_raw_window`，训练 1,284 窗口，验证 25 个配对 / 300 窗口；seed 42、batch 4、梯度累积 2、学习率 1e-4、context dropout 0.1、10 epoch。第 5/10 轮用 EMA、Heun16/K16 完整验证，按 11 缺失导联相关系数 `r_missing11` 选最佳。禁用与打乱评估均使用同一最佳权重。

## 验证结果

| 条件 | 11 导联 r ↑ | V1–V6 RMSE，μV ↓ |
|---|---:|---:|
| 原始 B5，无 context | 0.612632 | 623.351 |
| 旧冻结编码器，第 5 轮真实 context | 0.612270 | 618.521 |
| mean+std，第 5 轮真实 context（选中） | 0.612216 | 618.218 |
| mean+std，第 10 轮真实 context（未选中） | 0.611728 | 616.218 |
| mean+std 最优权重，禁用 context | 0.612632 | 623.351 |
| mean+std 最优权重，跨患者打乱 seed 101 | 0.612213 | 618.181 |
| mean+std 最优权重，跨患者打乱 seed 202 | 0.612209 | 618.129 |

mean+std 第 5 轮的 r 比旧冻结编码器低约 0.000054，胸导联 RMSE 低约 0.304 μV。相比原始 B5，其 r 低约 0.000416，胸导联 RMSE 低约 5.134 μV。正确配对的 r 只比两次打乱高约 0.000003 和 0.000007；RMSE 反而分别高约 0.037 和 0.088 μV。禁用 context 的汇总指标与原始 B5 相同。

## 机制检查与判断

25 个验证配对各取一窗口，零生成状态、流时间 0.5 下：embedding 跨患者两两余弦相似度均值 0.9912（旧冻结编码器为 0.9872）；瓶颈特征相对 RMS 调制均值 1.77%；开启/关闭 context 的速度场相对 RMS 差 1.06%。这些只是单一状态/时间的诊断，不代表完整采样过程。

新编码器确实影响预测，但 embedding 并未因加入标准差而变得更能区分患者；正确配对也未稳定优于打乱。不能把 RMSE 的小幅下降解释成有效利用患者特异 context。下一步应先检查体脂秤历史 ECG 与目标 ECG 的配对关系、采集时间和可迁移信号，再决定是否继续改变编码器或加入显式患者区分目标；不建议仅加大 FiLM 幅度。

证据边界：一个训练随机种子、25 个验证配对、两种打乱；最优轮次也在该验证集上选出。这不是独立测试成绩或两设备合并成绩。权重、训练日志、聚合指标和逐窗口预测/目标保存在本地受 Git 忽略的实验目录。远程实验目录的 45 个文件在本地逐文件通过 SHA-256 校验；重复的目标数组和禁用 context 预测是从本地已有的逐字节相同文件复制补齐。仓库只提交不含患者标识的汇总报告与代码。
