# B5 体脂秤 mean+std context 编码器试验（2026-10-15）

## 设计

本轮在 `context_body` 分支以固定原始 B5 EMA 初始化，只替换体脂秤 context 编码器的跨窗口汇总：逐窗口 masked CNN / 投影保持不变，将按有效采样点加权的窗口特征均值与标准差送入小型融合层。B5 主干、原 FiLM 注入方式和零初始化保持不变；仅训练编码器与 FiLM，共 173,856 个参数。独立输出目录为 `results/context_body/A_frozen_meanstd_v1/`，不覆盖旧实验。

沿用 `A_frozen_adapter_v1` 协议：体脂秤 `A_raw_window`，训练 1,284 窗口，验证 25 个配对 / 300 窗口；seed 42、batch 4、梯度累积 2、学习率 1e-4、context dropout 0.1、10 epoch。第 5/10 轮用 EMA、Heun16/K16 完整验证，按 11 缺失导联相关系数 `r_missing11` 选最佳。禁用与打乱评估均使用同一最佳权重。

## 验证结果

以下以本地 `control` 最优检查点（第 15 轮）为主比较基准。各组均在同一体脂秤验证集的 25 个配对 / 300 个窗口，以相同的 `joint_anchor_test_like` 输入协议、Heun16/K16、`r_missing11` 选模和 V1–V6 RMSE 口径计算。差值为“该组 − control”；r 越高越好，RMSE 越低越好。

| 组别（最优轮次） | 11 导联 r ↑ | 相对 control Δr | V1–V6 RMSE，μV ↓ | 相对 control ΔRMSE，μV |
|---|---:|---:|---:|---:|
| 本地 control，无 context（15） | 0.610313 | 0 | 609.759 | 0 |
| 首轮 A，原始体脂秤窗口 context（15） | 0.610435 | +0.000122 | 609.736 | −0.023 |
| 首轮 B，0.2 Hz 去趋势窗口 context（15） | 0.610352 | +0.000039 | 609.904 | +0.145 |
| 旧冻结编码器，真实 context（5） | 0.612270 | +0.001957 | 618.521 | +8.762 |
| mean+std，真实 context（5） | 0.612216 | +0.001903 | 618.218 | +8.459 |

新编码器与旧冻结编码器采用相同的冻结主干训练协议；新编码器的 r 低约 0.000054，RMSE 低约 0.304 μV。两种冻结试验与首轮 control/A/B **训练策略不同**：前者冻结 B5 主干、仅训练编码器与 FiLM、10 轮、学习率 1e-4；后者继续训练主干、20 轮、学习率 5e-5。因此以本地 control 为项目主基准可以描述最终指标差异，但不能将跨策略差异单独归因于 context 编码器。

为检验新模型是否利用正确患者配对，再固定 mean+std 的同一最佳权重，仅改变推理时的 context：

| mean+std 最优权重的推理条件 | 11 导联 r ↑ | V1–V6 RMSE，μV ↓ |
|---|---:|---:|
| 真实配对 | 0.612216 | 618.218 |
| 禁用 context | 0.612632 | 623.351 |
| 跨患者打乱 seed 101 | 0.612213 | 618.181 |
| 跨患者打乱 seed 202 | 0.612209 | 618.129 |

真实配对的 r 只比两次打乱高约 0.000003 和 0.000007；RMSE 反而分别高约 0.037 和 0.088 μV。“禁用 context”是该冻结模型的内部消融，不是本地继续训练过的 control；两者不能混称。

## 机制检查与判断

25 个验证配对各取一窗口，零生成状态、流时间 0.5 下：embedding 跨患者两两余弦相似度均值 0.9912（旧冻结编码器为 0.9872）；瓶颈特征相对 RMS 调制均值 1.77%；开启/关闭 context 的速度场相对 RMS 差 1.06%。这些只是单一状态/时间的诊断，不代表完整采样过程。

新编码器确实影响预测，但 embedding 并未因加入标准差而变得更能区分患者；正确配对也未稳定优于打乱。不能把 RMSE 的小幅下降解释成有效利用患者特异 context。下一步应先检查体脂秤历史 ECG 与目标 ECG 的配对关系、采集时间和可迁移信号，再决定是否继续改变编码器或加入显式患者区分目标；不建议仅加大 FiLM 幅度。

证据边界：一个训练随机种子、25 个验证配对、两种打乱；最优轮次也在该验证集上选出。这不是独立测试成绩或两设备合并成绩。权重、训练日志、聚合指标和逐窗口预测/目标保存在本地受 Git 忽略的实验目录。远程实验目录的 45 个文件在本地逐文件通过 SHA-256 校验；重复的目标数组和禁用 context 预测是从本地已有的逐字节相同文件复制补齐。仓库只提交不含患者标识的汇总报告与代码。
