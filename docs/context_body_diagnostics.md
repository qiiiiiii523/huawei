# B5 体脂秤 context 同条件诊断（2026-10-14）

本实验在同一批 25 个华为体脂秤验证配对、300 个窗口上比较，不训练或改写任何权重。输入目标、窗口顺序和评分代码一致；EMA、seed 42、Heun16、K16，输出与评分均为原始 μV。此处只是 Task 2 体脂秤分项，不是机器与体脂秤合并后的比赛总分。

| 条件 | 11 导联 r ↑ | V1–V6 RMSE，μV ↓ |
|---|---:|---:|
| 原始 B5（不继续训练） | 0.612632 | 623.351 |
| control（无 context 继续训练） | 0.610313 | 609.759 |
| A（正确配对 context） | 0.610435 | 609.736 |
| 同一 A 权重，禁用 context | 0.610391 | 609.961 |
| 同一 A 权重，跨患者打乱整条 context | 0.610462 | 609.719 |

原始 B5 的重评与交接表（r=0.612633，RMSE=623.354 μV）几乎一致。control 比原始 B5 的 r 低 0.002319，但胸导联 RMSE 低 13.592 μV，说明两项指标的变化方向不同。A 正确配对比 control 的 r 高 0.000122；25 配对 bootstrap 的 95% 区间约为 [−0.000099, 0.000324]。A 正确配对比同权重禁用 context 高 0.000044，但比本次跨患者打乱低 0.000027。适配器对预测有数值影响，却尚无证据表明它利用正确配对获得了稳定收益。

打乱目前只有一种固定映射；以上区间未覆盖重新训练或不同随机种子。下一步测量 context embedding 的跨患者差异、FiLM 调制幅度，并用多个独立跨患者映射复验。若正确配对仍不优于打乱，再考虑冻结 B5 主干后单独训练适配器。
