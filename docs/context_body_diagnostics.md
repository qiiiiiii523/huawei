# B5 体脂秤 context 同条件诊断（2026-10-14）

本实验在同一批 25 个华为体脂秤验证配对、300 个窗口上比较，不训练或改写任何权重。输入目标、窗口顺序和评分代码一致；EMA、seed 42、Heun16、K16，输出与评分均为原始 μV。此处只是 Task 2 体脂秤分项，不是机器与体脂秤合并后的比赛总分。

原始 B5 的重评与交接表（r=0.612633，RMSE=623.354 μV）几乎一致。control 比原始 B5 的 r 低 0.002319，但胸导联 RMSE 低 13.592 μV，说明两项指标的变化方向不同。A 正确配对比 control 的 r 高 0.000122；25 配对 bootstrap 的 95% 区间约为 [−0.000099, 0.000324]。A 正确配对比同权重禁用 context 高 0.000044，但比本次跨患者打乱低 0.000027。适配器对预测有数值影响，却尚无证据表明它利用正确配对获得了稳定收益。

以上区间未覆盖重新训练或不同随机种子。下述补充检查已用两个独立随机映射复验，未改动模型权重。

## 后续检查：适配器用量与多次打乱

在 25 个验证配对各取一个窗口，用相同锚导联、零初始生成状态和流时间 `t=0.5` 检查 A/epoch 15 的 context 路径。患者间 embedding 的两两余弦相似度均值为 0.478（范围 −0.655 至 0.999），并非恒定向量。FiLM 的 gamma、beta RMS 均值分别为 0.00290、0.00167；FiLM 对瓶颈特征的相对 RMS 改变量均值为 0.00356，同状态下真实 context 对比禁用 context 的速度场相对 RMS 改变量均值为 0.00329。说明路径确实产生差异，但当前调制幅度较小。这只是单一状态/时间的机制检查，不是完整采样效果的上界。

在同一 25 配对、300 窗口及完全相同的目标数组上，保持 A 权重和推理参数不变，仅以不同的跨患者整条记录替换 context：

| A 权重的 context 配对 | 11 导联 r ↑ | V1–V6 RMSE，μV ↓ |
|---|---:|---:|
| 真实配对 | 0.610435 | 609.736 |
| 原固定打乱 | 0.610462 | 609.719 |
| 随机打乱 seed 101 | 0.610435 | 609.961 |
| 随机打乱 seed 202 | 0.610385 | 609.884 |

三种打乱的配对映射两两有 23–24/25 个供体不同。真实配对的 r 比三种打乱的均值只高 0.0000074；RMSE 低 0.119 μV。这个均值仅为三次映射的描述性统计，不能当作可靠的显著性结论。单次打乱有时优于真实、有时差于真实；因此尚无稳定的“正确配对 context 提升”的证据。下一步不建议直接继续完整 B5 训练；应优先设计冻结 B5 主干、只训练 context 编码器和 FiLM 的小规模试验，配匹配的禁用/打乱对照，再决定是否扩大实验。

逐窗口预测、目标、配对 metadata、完整日志和权重保留在本地受 Git 忽略的 `results/context_body/`，不上传比赛原始数据或患者 ID。两次新增打乱的全量结果与远程文件逐文件通过 SHA-256 校验；远程 screen 会话已退出。
