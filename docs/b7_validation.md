# B7独立实现验证记录

日期：2026-10-24。范围：CPU行为测试与本地真实文件只读检查，不是ECG性能评估。

## 结果

`python -m unittest baselines.B7.tests.test_b7 -v`：18项通过。

- 正式64/128/256通道U7，输入40秒时输出形状为[1,7,20000]。
- stem收到的第一个通道与完整输入I逐点一致，后七通道等于当前生成状态；无独立I编码器或重建头。
- Heun每个中间评估的I保持相同，仅七通道状态更新。
- K16确实对16份不同keyed噪声输出求平均，噪声与batch顺序无关。
- 边缘扰动改变整窗MAE但不改变中央PCC；中央反相使PCC损失变化。
- II五倍权重按总有效权重归一化，常量失败预测不会从PCC评价消失。
- 无效导联NaN与人工边界不进入监督；边界样本mask排除重复标签位置。
- 10秒/40秒均可反向传播，梯度有限；40秒优化检查使用小通道配置以控制CPU成本。
- 12个中央核心块拼成120秒，原I与四个公式恢复导联一致；不同scale先转物理单位。
- 训练入口默认随机B7，B5 checkpoint被拒绝；同run中断后恢复的模型参数与连续训练逐张量相同。
- 推理包strict加载，导出前后同输入预测逐点一致。
- 患者跨split会报错，验证数据的大幅值不影响训练期拟合的scale，后续阶段冻结scale。
- WFDB多文件映射及有符号/无符号校验和均通过回归检查。

静态核查：15个Python文件可解析，无B5导入；3份B7阶段JSON配置通过校验。
