# B5 体脂秤局部注意力 context 编码器结果（2026-10-16）

## 实验设置

在 `context_body` 分支，仅把体脂秤六导联 context 编码器的窗口内池化改为带有效采样点 mask 的可学习时间注意力。输入仍是六导联原始波形及 mask；没有显式输入 33 维人工统计特征、诊断标签或中位心拍模板。跨窗口加权均值/标准差、FiLM 接入点、预处理和验证口径沿用上一版。注意力层零初始化，并从 `A_frozen_meanstd_v1/best.pt` 恢复其余编码器与 FiLM 权重；原 B5 主干和 FiLM 冻结，仅训练 `body_encoder.*`，共 107,873 个参数。

使用体脂秤 `A_raw_window` 数据，训练 1,284 窗口；验证 25 个配对、300 窗口。seed 42、batch 4、梯度累积 2、学习率 1e-4、10 epoch、context dropout 0.1。第 5/10 轮以 EMA、Heun16/K16 验证，按缺失 11 导联相关系数 `r_missing11` 选最佳。GPU 预检通过：编码器梯度 L1 为 0.046508，FiLM 梯度为 0，符合冻结设定。运行步骤见 [实验计划](context_body_attention_plan.md)。

## 结果

第 5 轮为最佳，`r_missing11=0.612042`；第 10 轮为 `0.611854`。下面四行均使用**同一个第 5 轮最佳权重**、同一验证名单和 Heun16/K16，只改变推理时的 context。相关系数越高越好，RMSE 越低越好；V1–V6 RMSE 是 Task 2 胸导联指标。

| 推理条件 | 缺失 11 导联 r ↑ | 缺失 11 导联平均 RMSE，μV ↓ | V1–V6 RMSE，μV ↓ |
| --- | ---: | ---: | ---: |
| 正确患者配对 | 0.612042 | 402.454 | 616.097 |
| 禁用 context | 0.612632 | 406.458 | 623.351 |
| 跨患者打乱，seed 101 | 0.612025 | 402.340 | 615.998 |
| 跨患者打乱，seed 202 | 0.612015 | 402.224 | 615.723 |

正确配对的 r 仅比两次打乱高 0.000017、0.000027；V1–V6 RMSE 则分别高 0.099、0.374 μV。禁用 context 后 r 略高，但 RMSE 明显变差，表明模型输出受 context 影响；仅凭这一点不能认定它使用了正确患者的信息。两次打乱都没有在主要误差口径上劣于正确配对，因此本次没有观察到稳定的患者配对收益。

上一版冻结主干的 mean+std 编码器在正确配对下为 `r=0.612216`、V1–V6 RMSE `618.218 μV`。本版的 r 低约 0.000174、RMSE 低约 2.121 μV；本版从上一版权重继续初始化并只训练编码器，所以跨版差异不能单独归因于注意力结构。本地继续训练主干的 `control` 是另一训练策略，其 `r=0.610313`、V1–V6 RMSE `609.759 μV`，不作为本次编码器消融的直接对照。

## 表示诊断

验证集每个患者取一个目标窗口，计算 context embedding 的两两余弦相似度，以及零生成状态、流时间 0.5 的 FiLM/速度场变化：

| 指标 | 本版注意力 | 上版 mean+std |
| --- | ---: | ---: |
| 跨患者 embedding 余弦相似度均值 | 0.973772 | 0.991194 |
| 跨患者 embedding 余弦相似度中位数 | 0.992430 | 0.996968 |
| 瓶颈特征相对 RMS 调制均值 | 2.683% | 1.769% |
| 启用/禁用 context 的速度场相对 RMS 差均值 | 1.570% | 1.063% |

相似度均值下降，说明部分患者的表示拉开了距离；中位数仍高，且推理打乱未稳定变差。FiLM/速度场数值只对应一个固定状态和时间，不能代替完整采样的效果判断。

## 判断与下一步

这版时间注意力改变了表示和输出，却没有在正确配对对照中形成稳定优势。按原计划，可另开一个显式心拍形态与 RR/节律分支实验；先保留此版最佳权重、固定 B5/FiLM 与相同验证协议，再比较单独心拍、单独节律和融合版本。两设备记录不同步，心拍应在各自记录内独立提取并汇总，不做逐拍硬配对。当前结果不支持仅继续增大 FiLM 幅度。

结论限于单一随机种子和 25 个验证配对；最佳轮次也由这个验证集选出，尚非独立测试成绩。
