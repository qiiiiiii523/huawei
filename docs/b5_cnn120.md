# B5-final-exp-cnn120：整段CNN感受野对照

从固定的 `B5-final@9f3e962` 创建。它与 G120 不同：不增加注意力修正支路，而是直接以完整120秒的50Hz同步I运行原P慢CNN，并增加两个残差块。

| 组 | 完整120秒推理 | 新增 dilation | 目的 |
|---|---|---|---|
| L120 | 是 | `(1, 1)` | 控制“去除50秒窗口拼接”本身的影响 |
| C120 | 是 | `(256, 256)` | 理论感受野约122.8秒，检验长程CNN信息 |

两组继承同一P-S50权重。新增块的第二卷积全零初始化，所以第0轮两组输出严格一致；P-S50、FM、body均不更新。它们的第0轮可不同于原Final，因为原P此前是50秒窗口、中央10秒输出，而这里是整段120秒一次前向。

第一轮只用华为训练患者更新完整CNN，保持原P慢损失与Final评分。若C120同时超过Final和L120，才做新seed复核；公开PTB长记录适配留给通过初筛后的正式路线。

服务器启动：

```bash
cd /home/qht/huawei_B5_final_exp_cnn120
conda activate BioFlow
bash scripts/run_b5_cnn120.sh --gpu 0
```

脚本依次复现固定Final、生成不可变训练缓存、训练L120/C120、复评best/last并输出 `comparison/summary.md`。结果根目录为：

```text
/home/qht/huawei/results/B5-final-exp-cnn120/run_时间_PID/
```

训练启动后不需要轮询；完成时查看该目录的 `comparison/summary.md`。中断恢复必须对同一组使用其 `last.pt`，并保持原 `shared/study.json` 不变。
