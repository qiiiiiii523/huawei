# FM+Unet 两组提分实验（2026-10-26）

A wide3：通道96/192/384，3个分辨率，2次下采样，原9个瓶颈块(d=1,1,1,1,2,3,6,13,26)，时间/人口学维度32；10,312,991参数。

B adaptive7：通道64/128/256/256/256/256/256，7个编码处理层级，时间/人口学128维，瓶颈9块(d=1,1,1,2,2,2,3,3,4)，15,988,319参数。6个通道过渡中，仅在减半后仍>=8点时stride2，否则同一kernel4通道映射改stride1，以左1右2零填充保持长度；解码按跳连精确对齐。短10秒50点->25->12->12->12->12->12；75秒375->187->93->46->23->11->11；120秒600->300->150->75->37->18->9。因此它是7处理层级，不承诺短窗7个不同分辨率。

两组全部5Hz慢状态、原始I保留500Hz；固定快、scale/noise和原损失不变。真实batch64，FP32，不做梯度累积。AdamW weight_decay=.01，EMA=.999，clip1，seed42。public10/public75/huawei120预算20000/8000/8000，学习率1e-4/5e-5/2e-5。恢复点每500更新；public10仅20000验证，后两阶段4000/8000验证，Heun16/K16。验证逐记录、每条16轨迹；不做初始完整验证。

训练器在每次验证前保存last.pt，验证后保存step_XXXXXXX.pt；best.pt是已验证候选中r最高的完整检查点，final.pt是最后8000/20000检查点，两者不能混用。后续阶段从上一阶段best.pt的EMA初始化并重置优化器，必须上一任务成功才释放；公开/PTB按慢分量r选择，华为按固定快+新慢完整120秒11导联原QC分组评分选择。最佳部署文件best_inference.pt，最后一步部署文件inference.pt。仅比较4000/8000，无法精确识别过拟合开始时点。

验证不改变后续训练RNG，恢复能够重做中断验证再继续更新。新训练检查点保持原architecture_id以支持旧已完成阶段初始化，但模型配置（含min_bottleneck_points）必须完全匹配；源代码SHA变化会拒绝旧运行的精确resume。本次部署到独立服务器工作树，不改旧训练代码或旧实验结果。

通过现有/home/qht/train_scheduler管理：先提交有界真实batch64显存profile（每阶段2次AdamW/EMA更新、K16Heun16慢推理、华为包含固定快完整120秒推理），成功后按实际reserved/进程采样峰值加余量提交6个训练任务，每个任务一个阶段。使用调度器GPU UUID，不在训练脚本中覆盖CUDA_VISIBLE_DEVICES；本组沿用物理GPU2约束。profile为独立短实验，训练随机初始化，不复用profile权重。GPU采样峰值仅为下界，预算保留额外余量。

配置：configs/fm_unet_followup/{wide3,adaptive7}/{public10,public75,huawei120}.json。
