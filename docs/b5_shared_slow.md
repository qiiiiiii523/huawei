# 方向4第一轮：独立基线上的共享慢误差筛查

基线是原 B5-final（原body仅改II、机器原FIR25），不叠加方向2的C3。
所有候选只修改V1--V6，I、肢体和设备context逐点保持不变。
复用纯FM+P验证预测；仅重算冻结P慢预测，不重跑FM。

## 验证顺序

1. 对训练/验证目标按物理目标记录去重，严格检查患者划分。
2. 使用完整120秒MA501目标慢曲线、冻结P的50Hz输出，残差为目标慢曲线减0.75P。
   去每条记录/导联常量，用训练时d12尺度归一化，不用目标振幅作缩放。
3. 在训练中六胸导联QC全合格的患者记录上拟合PCA基底，按患者平衡；
   不合格导联不填0。分别分析真实慢曲线和慢预测误差。
4. 将训练基底固定，在留出患者上按可用导联做掩码最小二乘重建。
   这一步使用了目标来求系数，只是oracle结构上界，绝不是部署能力。
5. 固定相同训练数据和当前I/人口学输入，比较逐导联线性修正、rank2共享、rank3共享。
   I局部均值、RMS、MA501特征按2秒间隔的滞后提取，单点可见范围小于50秒；
   所有探针输入相同。标准化和ridge(.01)只拟合训练数据，不调验证参数。
6. 使用实际生成的修正波形，按正式完整120秒口径重算Task1、机器、body、总r及逐导联。

rank2/3探针是对同一个独立ridge预测加训练PCA输出子空间约束，
用来筛查误差结构是否可预测；不将它等同于最终的共享+独有神经网络。
本轮不训练最终新CNN，也不叠加长程输入、胸导联交互或新历史表示。

## 输出

- pca_spectrum.csv：训练集真值/误差的秩与累计能量。
- heldout_structure.csv：训练基底在留出患者上的oracle解释度、QC排除数量。
- predictability.csv：共同I输入下三种线性探针的留出慢误差解释度。
- summary.csv：原B5-final与各探针的完整r变化。
- scores/：各组实际预测、逐导联和逐患者/配对评分。
- slow_cache/：冻结P和监督慢曲线、输入特征、划分与数据哈希。
