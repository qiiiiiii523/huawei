# B5 → B7-U7权重使用决策

确认日期：2026-10-24。决策：首轮默认部分迁移B5兼容参数，然后全量适配训练U7。

## 为什么采用，是否必须

迁移是初始化策略：复用同一ECG生成任务和同构U-Net隐藏层已有的参数，降低重新学习成本，再用公开真实10秒数据学习新接口。它合理但不保证有效，并非B7运行的必要条件。没有实际ECG验证结果证明迁移优于随机初始化；需要独立比较时用同一U7架构和训练预算做随机初始化对照。

只改10秒为40秒时旧B5可整网加载；现在I接入与生成通道都变了，整网严格继承的旧结论已不适用。原B5、迁移U7的initial和训练后的U7是三个独立候选。

## 迁移清单

| 部分 | 处理 |
|---|---|
| encode0/1、bottleneck、decode1/0 | 名称、通道、卷积配置一致时复制 |
| down1/2、up1/0、merge1/0 | 配置和形状一致时复制 |
| 时间与人口学编码、块内时间投影/FiLM | schema和维度一致时复制 |
| stem七个生成状态输入列 | 从原missing11索引[0,5,6,7,8,9,10]按顺序提取 |
| 新stem的干净I列 | 用旧anchor_full与condition_enc[0]的线性组合初始化；bias明确合并 |
| 输出头7行及bias | 同样使用原missing11索引[0,5,6,7,8,9,10] |
| 旧I多尺度支路、后续I投影与I重建头 | 明确删除，不进入新state_dict |
| 旧优化器、训练进度与best账本 | 不继承；新建B7阶段状态 |

原missing11顺序II、III、aVR、aVL、aVF、V1～V6。全12导联索引和missing11索引不能混用。独立I路径已改为直连，线性合并只初始化第一层贡献，不保持原网络函数等价。

迁移必须逐张量报告来源、目标、形状和动作，检查复制数量与遗漏清单。不能用strict=False后忽略所有错误。转换后保存新架构ID；未来U7 checkpoint在自身架构中strict加载。

## 训练与验收

1. 先核实源SHA、model_config、scale、schema，完成原B5纯FM基线。
2. 执行显式迁移，保存迁移报告与U7 initial，核对干净I不加噪、七维path及输出顺序。
3. U7默认全部可训练，PTB-XL+Chapman真实10秒适配，得到共同P；新建优化器与EMA初值。
4. P分别开展华为40秒A路线、PTBDB40秒后华为40秒B路线；B不从A的best开始。
5. 每阶段initial可胜出，保留best_r/last；同协议本阶段last才用于精确resume。

如资产身份不匹配，不能强行迁移；核对正确资产或另立明确的随机初始化运行。T7纯Transformer不适用本迁移清单，UT7可从同一个已训练U7增加零初始化残差输出模块，与同源U7继续训练匹配比较。

本文件确认的是方案与静态代码兼容范围，不是实际权重迁移成功报告。
