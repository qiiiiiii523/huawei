# C/M/F本地实现核对

来源：B5-exp提交bb3a4d1，继承其最新B5评分基础db4b29f。独立worktree实现，不切换或改动桌面主工作区。

CPU合成测试覆盖：

- C损失与原损失逐值一致；M仅增加均值项，F仅增加目标匹配残差项。
- 完整120秒均值误差、额外振荡、标签自身振荡、NaN坏导联屏蔽及有效梯度。
- S30旧权重严格加载、同一初始参数、只读取I/人口学、无训练量级预检。
- 第0轮候选保存，慢r与组合总分分别选模，last恢复优化器/RNG/数据顺序；模拟损坏候选并恢复。
- 周期组合评分与最终评估一致，正常导联与完整原始评分分开，快残差/波峰大点/窗口边界诊断输出。
- 三组比较拒绝不等训练预算、不同损失以外的配置变化和过期checkpoint评估。
- 原prepared/check/evaluate/compare工作流以及B5评分/120秒输入规则兼容性。
