# B5 体脂秤 context 首轮实验（2026-10-13）

## 实验与数据

- 三组均由同一 B5 基础 `best.pt` 的 EMA 权重独立初始化；`control` 不使用 context，A 使用原始跨设备体脂秤窗口，B 使用 0.2 Hz 去趋势后的窗口。跨设备导联仅作 context，不直接作为待预测导联。
- 华为体脂秤训练集 1,284 个目标窗口；验证集 300 个窗口、25 条记录。三组均训练 20 epoch，seed 42、batch size 4、梯度累积 2、学习率 5e-5；每 5 epoch 验证一次，Heun 16 步、16 次采样。
- 三组按体脂秤验证子集的 `r_missing11` 选最佳权重，均选中 epoch 15。指标是原始 μV 尺度，按记录拼接窗口后计算相关性；胸导联 RMSE 取 V1–V6。

## 最佳权重比较

| 组别 | 11 个缺失导联 r（越高越好） | V1–V6 平均 RMSE，μV（越低越好） | 11 导联平均 RMSE，μV |
|---|---:|---:|---:|
| control | 0.610313 | 609.759 | 400.297 |
| A：原始窗口 | 0.610435 | 609.736 | 400.221 |
| B：去趋势窗口 | 0.610352 | 609.904 | 400.365 |

相对于 control，A 的 r 高 0.000122、胸导联 RMSE 低 0.023 μV；B 的 r 高 0.000039，但胸导联 RMSE 高 0.145 μV。两种 context 的变化都非常小，当前不能据此断定有稳定收益，也不能把验证集结果当作比赛最终成绩。若只在本轮候选中选一个继续研究，A 略优于 B。

## 解读边界与下一步

本轮只有一个随机种子和 25 条体脂秤验证记录；未做重复种子、配对置信区间或独立测试。基础 B5 旧表中的体脂秤 r=0.612633、胸导联 RMSE=623.354 μV，可作历史背景，但它与本轮三组在训练/选模条件上不同，不能直接归因于 context。当前最可靠的对比是同轮的 control、A、B。

建议先核实 context 配对、可用率和零初始化适配器的学习幅度，再做多种子重复与配对评估。只有获得稳定收益后，才考虑更复杂的 context 聚合结构。
