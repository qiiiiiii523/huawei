# B5 体脂秤冻结主干适配器试验（2026-10-14）

## 设计

- 从交接的固定 B5 `results/B5/context_start/best.pt` EMA 初始化；原 B5 参数逐张量冻结，只训练 `body_encoder` 和 `body_film`，共 124,448 个可训练参数。训练仍经完整 B5 前向/反向传播，但优化器不包含 B5 参数；主干保持 `eval()`，关闭元数据 dropout。
- 独立输出目录 `results/context_body/A_frozen_adapter_v1/`，不覆盖原 B5、control、A 或 B。仍用体脂秤 `A_raw_window`、相同 Flow Matching 损失、训练 1,284 窗口、验证 25 配对/300 窗口。seed 42，batch 4、累积 2、context dropout 0.1、AdamW、学习率 1e-4，训练 10 epoch；第 5、10 轮以 EMA、Heun16/K16 完整验证，并按 `r_missing11` 选最佳。
- 该试验同时改变了首轮 A 的训练范围、学习率、总轮数和主干训练模式，**不能把它与首轮 A 的差异单独归因于冻结操作**；它用于测试一条低成本、主干不漂移的适配路径。

## 验证结果

| 权重/评估条件 | 11 导联 r ↑ | V1–V6 RMSE，μV ↓ |
|---|---:|---:|
| 原始 B5，无 context | 0.612632 | 623.351 |
| 冻结适配器，第 5 轮，真实 context（按 r 选中） | 0.612270 | 618.521 |
| 冻结适配器，第 10 轮，真实 context（未选中） | 0.611824 | 616.382 |
| 第 5 轮同一权重，禁用 context | 0.612632 | 623.351 |
| 第 5 轮同一权重，跨患者打乱 seed 101 | 0.612267 | 618.489 |
| 第 5 轮同一权重，跨患者打乱 seed 202 | 0.612262 | 618.439 |

第 5 轮真实 context 相比原始 B5，r 低约 0.000362，胸导联 RMSE 低约 4.83 μV。禁用 context 后，300 个窗口的预测与原始 B5 **逐点完全相同**，并非只在汇总指标上接近；两次打乱与真实 context 使用逐点相同的目标数组，且两种打乱的 25 个供体中有 24 个不同。真实 context 比两次打乱的 r 仅高约 0.0000034 和 0.0000077，但 RMSE 分别高约 0.033 和 0.083 μV。这些极小的差值不构成稳定的患者正确配对收益。

## 适配器机制检查与结论

25 个验证配对各取一窗口，在零生成状态、流时间 0.5 下，新权重的 FiLM 对瓶颈特征相对 RMS 调制均值为 1.52%，高于首轮 A 的 0.36%；同状态下开启/关闭 context 的速度场相对 RMS 差为 0.98%。但新 context embedding 的跨患者两两余弦相似度均值为 0.987，明显趋于相似（首轮 A 为 0.478）。这些是单一状态/时间的诊断，不代表完整采样的调制幅度。

冻结试验验证了：当前适配器可改变输出、主干确实保持固定，但更强的调制并未带来可靠的正确配对收益。下一步不宜单纯放大 FiLM；应先检查 context 编码器是否学成了近似全局偏置，以及体脂秤历史 ECG 是否含有可迁移到目标导联的患者特异信息。若继续改结构，应在固定验证协议下加入明确的患者区分/配对对照，并保持与禁用、跨患者打乱的比较。

证据边界：仅一个训练随机种子、25 个验证配对和两种随机打乱；最佳轮次也在这同一验证集上选出。这里不是独立测试成绩或比赛两设备合并成绩，不能据此声称 context 永远无用。

训练、推理、审计均正常结束。权重、逐窗口预测、目标、metadata、日志和配置留在本地受 Git 忽略的 `results/context_body/A_frozen_adapter_v1/`；远程结果也保留。远程实验目录 41 个文件和训练日志均已复制到本地并逐文件通过 SHA-256 校验。仓库只提交代码与不含患者标识的汇总报告。
