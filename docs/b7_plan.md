# B7-T当前方案：只替换Transformer架构

日期：2026-10-24。版本T1。从B7@1615b21创建独立分支；本分支使用一维多尺度时序Transformer，原B7分支保留U7。数据、损失、窗口、采样、优化预算和评分口径全部沿用B7。尚未执行真实训练。

## 1. 模型要求与实现

| 要求 | 实现 |
|---|---|
| 完整I直接输入 | `model.py`中沿通道拼接`anchor,state`，没有独立I编码支路 |
| I不加噪 | `flow.py`仅构造7通道随机状态；每个ODE子步骤使用同一个I |
| 输入8通道 | I+II、V1～V6的7条状态，共8 |
| 输出40秒 | 500Hz时网络输出7×20000的完整速度，ODE得到7×20000波形 |
| 输出8条独立波形 | 原I直接保留，加上7条生成波形；I不另训练重建头 |
| 最终12导联 | 在μV下推导III、aVR、aVL、aVF，按标准顺序组合 |
| 中央10秒PCC | 40秒时取采样索引7500:12500，即15～25秒 |
| 完整40秒MAE | 只排除无效导联/人工位置，不裁掉真实边缘 |
| II加权 | FM、MAE、PCC均以(5,1,1,1,1,1,1)做有效权重归一化 |
| 初始化 | 固定seed随机初始化B7，不读取或转换B5权重 |
| 采样 | Heun16、K16份波形逐点平均、seed42、EMA |
| 拼接选模 | 中央10秒步长10秒拼完整120秒，按最终11导联指标选best_r |

T使用128/256/384三尺度时序Transformer，共12个块，细层/中层采用64-token局部平移窗口，粗层采用全局注意力。10点(20毫秒)共享patch完整接收I与七条状态，输出逐点恢复七通道速度；没有独立I编码分支或卷积骨干。时间与人口学编码接口保留，通过自适应LayerNorm注入。逐层尺寸见[b7_architecture.md](b7_architecture.md)。

## 2. Flow与Loss

固定生成顺序J=(II,V1,V2,V3,V4,V5,V6)。仅为这七条生成z：

\[
x_t=(1-t)z+t y_J,\qquad v^*=y_J-z,
\qquad v_\theta=f_\theta([I,x_t],t,m).
\]

I经可逆固定尺度归一化，所有t保持不变；不参与path、噪声、I监督或ODE更新。

训练终点估计为`x_t+(1-t)*v_theta`，总loss为：

\[
L=L_{FM}+1.0L_{MAE}+0.1L_{PCC}.
\]

40秒阶段FM/MAE覆盖完整真实有效窗口；PCC只用中央15～25秒。10秒公开阶段PCC使用真实完整10秒。默认目标方差阈值1e-8。预测失败近乎常量仍计入PCC，不能因此排除；真实目标近乎常量按固定规则排除其PCC。各项、II和胸导联分项独立记录。

I不计算生成loss；四个派生导联不重复加权。II权重5是老师建议的首轮候选，不是已验证最优。上述lambda与预算均为可审计起始配置，不是性能结论。

## 3. 十二导联恢复

在统一μV、同一时间轴上：

```text
III = II-I
aVR = -(I+II)/2
aVL = I-II/2
aVF = II-I/2
```

各导联scale可能不同，必须先还原物理单位。II和V1～V6联合生成，不先预测II再把预测II串行喂给胸导联。II误差会线性影响派生导联，加权不能消除I本身的测量误差。

## 4. 数据与阶段顺序

1. 从随机B7-T开始：PTB-XL+Chapman真实10秒联合预训练，得到P_T；不重复、拉伸或跨患者拼长。
2. T-A路线：从P_T直接华为真实40秒适配。
3. T-B路线：同一P_T先PTBDB真实40秒得到Q_T，再同预算华为40秒。B_T不从A_T的华为best开始。
4. P_T成功结束后A_T和Q_T可并行；B_T只依赖Q_T成功结束。不直接使用U7的P/Q/A/B权重。

所有阶段只允许相同配置的B7-T checkpoint作为下一阶段初始化，新建优化器与best账本。同run的last可精确resume，核对源码、配置/预算、manifest和实际记录SHA。数据缓存可复用，原U7训练权重不兼容。参数初始化见[b7_initialization.md](b7_initialization.md)。

所有患者先划分再切窗。PTB-XL使用官方patient/fold，Chapman/PTBDB按source+patient固定hash划分；有既定数据治理时用显式index覆盖。公共默认QC只检查有限数据，华为必须提供既定可靠I/逐导联QC。不能把训练集重新叫作验证集，也不能将同一患者的不同记录划到不同集合。

公开训练scale由B7训练划分拟合，各导联训练记录P95-P5范围的中位数、下限100μV，anchor与d12-I共享尺度。后续`--scale-manifest`冻结这份B7 scale。没有B5 scale依赖。

准备工具支持.hea、完整d12.xml、原始μV NPZ。华为`huawei_index.py`沿用原B7明确的`same_record_target_I`：同步d12的I为输入，原手表/d6仅用于保留配对分组，不作为同步波形输入。患者划分与QC不变。详见[b7_server_data.md](b7_server_data.md)；不宣称已完成其他设备I的部署评估。

本轮新增读取器只读验证过华为XML、PTB-XL、Chapman普通及JS01052、PTBDB各样例。不是新增全量数据审计。历史公式关系抽查仍为每来源16份，共64份，见[b7_limb_relation_audit.json](b7_limb_relation_audit.json)。

## 6. 推理与最终评分

每个40秒窗口从七通道噪声经Heun16生成，K16取均值，保留中央10秒。核心[s,s+10)对应输入[s-15,s+25)，以10秒步长拼成120秒，共12窗。首尾重复可见端点，不使用隐藏目标作条件；训练边界样本的人工位置排除监督。

I原样保留，将拼好的七条波形还原μV后恢复四条派生输出。最终只对11条缺失导联计算完整记录r，II评估权重不乘5。必须逐导联先在物理target内平均配对，再target等权，最后平均11导联（不能先平均每条记录的可用导联）；华为R=0.5Task1+0.25机器+0.25体脂秤。未定义Pearson沿用原公共评分器规则。华为三组缺失、目标QC不一致或不是完整120秒时拒绝选模。

公开验证使用真实完整10秒块，尾部不足一个块不补成标签；训练仍可从整条真实记录取随机窗口。公开阶段按来源等权的完整预测r选阶段候选，不能与华为R直接横比。每阶段initial可胜出，保存best.pt及同候选best_r.pt、last，另可导出不含优化器/数据的推理包。训练日志单独记录window_r，验证r另存。

## 7. 已实现入口

- `model.py`、`flow.py`、`losses.py`、`leads.py`：独立模型与目标。
- `prepare.py`、`data.py`：公开自动索引/显式QC配对索引、缓存、真实窗口、训练期scale。
- `train.py`、`checkpoint.py`：随机初始化、B7阶段初始化、EMA、验证选模、精确恢复。
- `inference.py`、`evaluate.py`、`package.py`：只读可见条件的生成、完整记录评分、独立包。
- `configs/b7_public10.json`、`b7_public40.json`、`b7_huawei40.json`：首轮预算和loss/采样配置。
- `tests/test_b7.py`、`test_transformer.py`、`test_huawei_index.py`：原B7行为、架构和元数据桥接检查。

可复制的命令、index字段与依赖见[运行说明](../baselines/B7/README.md)。测试中临时小网络、K1/一步采样仅用于CPU功能检查，正式Transformer配置为128/256/384、12个注意力块、Heun16/K16。没有新增真实模型成绩，未执行真实公开预训练或华为微调。
