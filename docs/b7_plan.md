# B7-U7当前方案：独立训练，不继承B5

日期：2026-10-24。版本v4。用户最新决定取消B5权重迁移；本文件替代v1～v3的默认迁移方案。U7已实现并完成CPU合成行为检查，尚未在真实ECG上训练。UT7/T7仍是后续架构候选。

## 1. 模型要求与实现

| 要求 | 实现 |
|---|---|
| 完整I直接输入 | `model.py`中沿通道拼接`anchor,state`，没有独立I编码支路 |
| I不加噪 | `flow.py`仅构造7通道随机状态；每个ODE子步骤使用同一个I |
| 输入8通道 | I+II、V1～V6的7条状态，共8 |
| 输出40秒 | 500Hz时网络输出7×20000的完整速度，ODE得到7×20000波形 |
| 输出8条独立波形 | 原I直接保留，加上7条生成波形；I不另训练重建头 |
| 最终12导联 | 在μV下推导III、aVR、aVL、aVF，按标准顺序组合 |
| 中央10秒PCC | 40秒时取采样索引7500:12500，即15～25秒 |
| 完整40秒MAE | 只排除无效导联/人工位置，不裁掉真实边缘 |
| II加权 | FM、MAE、PCC均以(5,1,1,1,1,1,1)做有效权重归一化 |
| 初始化 | 固定seed随机初始化B7，不读取或转换B5权重 |
| 采样 | Heun16、K16份波形逐点平均、seed42、EMA |
| 拼接选模 | 中央10秒步长10秒拼完整120秒，按最终11导联指标选best_r |

U7使用64/128/256三尺度一维U-Net，共12残差块，瓶颈dilation1/2/4/8。时间128维嵌入与人口学128维FiLM保留。直接I指主干入口为完整波形，不保证后续卷积特征绝对无信息损失。逐层尺寸见[b7_architecture.md](b7_architecture.md)。

## 2. Flow与Loss

固定生成顺序J=(II,V1,V2,V3,V4,V5,V6)。仅为这七条生成z：

\[
x_t=(1-t)z+t y_J,\qquad v^*=y_J-z,
\qquad v_\theta=f_\theta([I,x_t],t,m).
\]

I经可逆固定尺度归一化，所有t保持不变；不参与path、噪声、I监督或ODE更新。

训练终点估计为`x_t+(1-t)*v_theta`，总loss为：

\[
L=L_{FM}+1.0L_{MAE}+0.1L_{PCC}.
\]

40秒阶段FM/MAE覆盖完整真实有效窗口；PCC只用中央15～25秒。10秒公开阶段PCC使用真实完整10秒。默认目标方差阈值1e-8。预测失败近乎常量仍计入PCC，不能因此排除；真实目标近乎常量按固定规则排除其PCC。各项、II和胸导联分项独立记录。

I不计算生成loss；四个派生导联不重复加权。II权重5是老师建议的首轮候选，不是已验证最优。上述lambda与预算均为可审计起始配置，不是性能结论。

## 3. 十二导联恢复

在统一μV、同一时间轴上：

```text
III = II-I
aVR = -(I+II)/2
aVL = I-II/2
aVF = II-I/2
```

各导联scale可能不同，必须先还原物理单位。II和V1～V6联合生成，不先预测II再把预测II串行喂给胸导联。II误差会线性影响派生导联，加权不能消除I本身的测量误差。

## 4. 数据与阶段顺序

1. 从随机B7开始：PTB-XL+Chapman真实10秒公开预训练，得到P；不把短记录重复、拉伸或跨患者拼长。
2. U7-A先做：从P直接华为真实40秒适配。
3. U7-B后做：同一P先PTBDB真实40秒，再同预算华为40秒。B不从A的华为best开始。
4. 选定数据路线后，另行实现UT7，与同起点U7继续训练做匹配比较。
5. 预算允许时另行实现纯Transformer T7，重新公开预训练。当前不提供UT7/T7运行入口。

所有阶段只允许B7自己的checkpoint作为下一阶段初始化，新建优化器与best账本。同run的last可精确resume，核对源码、配置/预算、manifest和实际记录SHA。参数初始化细节见[b7_initialization.md](b7_initialization.md)。

所有患者先划分再切窗。PTB-XL使用官方patient/fold，Chapman/PTBDB按source+patient固定hash划分；有既定数据治理时用显式index覆盖。公共默认QC只检查有限数据，华为必须提供既定可靠I/逐导联QC。不能把训练集重新叫作验证集，也不能将同一患者的不同记录划到不同集合。

公开训练scale由B7训练划分拟合，各导联训练记录P95-P5范围的中位数、下限100μV，anchor与d12-I共享尺度。后续`--scale-manifest`冻结这份B7 scale。没有B5 scale依赖。

准备工具支持.hea、完整d12.xml、原始μV NPZ。支持两个短窗集一起准备。可见手表I等需先完成真实时间对齐，传入`anchor_uV`，不得用目标I冒充设备输入。XML默认选最长完整12导联，华为截取前120秒；有其他物理起点时先构造正确配对NPZ。

## 5. 真实数据读取核查与更正

本地已核对PTB-XL的21799份高采样率记录和Chapman45152份记录均为10秒；PTBDB548份中495份长度至少50秒。时长检查不等于医学QC筛选。

**更正此前PTBDB判断：头文件15通道是正常的WFDB多文件布局；标准12条位于.dat，另3条Frank导联位于.xyz，不是头损坏。** 新读取器按每条信号的文件映射选择标准12导联，校验初值和16位校验和，不改原始文件。旧报告中的“异常头需修正”解释已撤销，数值关系报告保留并注明更正。

Chapman的JS01052.hea确有异常第一行，独立读取器仅对该已知记录验证MAT4布局后恢复完整12×5000波形。其余WFDB也校验大小、初值、checksum(兼容有符号与无符号表示)。

本轮新增读取器只读验证过华为XML、PTB-XL、Chapman普通及JS01052、PTBDB各样例。不是新增全量数据审计。历史公式关系抽查仍为每来源16份，共64份，见[b7_limb_relation_audit.json](b7_limb_relation_audit.json)。

## 6. 推理与最终评分

每个40秒窗口从七通道噪声经Heun16生成，K16取均值，保留中央10秒。核心[s,s+10)对应输入[s-15,s+25)，以10秒步长拼成120秒，共12窗。首尾重复可见端点，不使用隐藏目标作条件；训练边界样本的人工位置排除监督。

I原样保留，将拼好的七条波形还原μV后恢复四条派生输出。最终只对11条缺失导联计算完整记录r，II评估权重不乘5。组内先配对聚合到物理target，再target等权；华为R=0.5Task1+0.25机器+0.25体脂秤。华为三组缺失、目标QC不一致或不是完整120秒时拒绝选模。

公开验证使用真实完整10秒块，尾部不足一个块不补成标签；训练仍可从整条真实记录取随机窗口。公开阶段按来源等权的完整预测r选阶段候选，不能与华为R直接横比。每阶段initial可胜出，保存best_r、last，另可导出不含优化器/数据的推理包。
