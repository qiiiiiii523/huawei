# B5-1022：G120 与 C3 三组组合实验

## 目的

在同一个 G120 `best.pt` 和同一验证人群上完成三组正式对照：

|组别|说明|是否训练|
|---|---|---|
|A|G120＋原 body 路由|否|
|B|G120＋队友已有 C3|否，只迁移评估|
|C|G120＋在 G120 基础预测上重新训练的 C3|只训练 body/C3 adapter|

FM、P 和 G120 在三组中全部冻结。C 组从固定的原 `body.pt` 初始化，不从 B
组继续训练，避免把“更换基础预测”和“旧 C3 暖启动”混在一起。三组都按完整
`R=0.5×Task1 r+0.5×Task2 r` 比较；Task2 内机器与体脂秤设备等权。

```text
/home/qht/huawei/results/B5-final-exp-slow120/run_20261021_140544_2522863/G120/best.pt
```

对应共享缓存应为：

```text

```

## 分阶段运行与中断恢复

先定义路径：

```bash
slow_root=/home/qht/huawei/results/B5-final-exp-slow120/run_20261021_140544_2522863
run=/home/qht/huawei/results/B5-1022/g120_c3_seed42_v1
old_c3=/填写队友预先确定的旧C3/best.pt
```

### 1. A 组：G120＋原 body

```bash
python -u -m baselines.B5_slow120.evaluate \
  --run "$slow_root/shared" \
  --checkpoint "$slow_root/G120/best.pt" \
  --output "$run/group_A_g120_original_body" \
  --device cuda --keep-predictions
```

### 2. 生成 G120-C3 缓存

```bash
python -u -m baselines.B5_final.g120_c3 prepare \
  --slow-run "$slow_root/shared" \
  --slow-checkpoint "$slow_root/G120/best.pt" \
  --group-a-evaluation "$run/group_A_g120_original_body" \
  --output "$run/cache" --device cuda
```

如果缓存阶段中断且 `cache/cache.json` 已存在，确认代码、权重、数据和 A 组输出均
未改变后，在同一命令末尾增加 `--resume`。缓存完成后不要再使用 `--resume` 覆盖。

### 3. B 组：G120＋旧 C3

```bash
python -u -m baselines.B5_final.g120_c3 evaluate \
  --cache "$run/cache" --checkpoint "$old_c3" \
  --output "$run/group_B_g120_old_c3" \
  --label G120+old_C3 --device cuda
```

### 4. C 组：在 G120 上训练新 C3

```bash
python -u -m baselines.B5_final.g120_c3 train \
  --cache "$run/cache" --output "$run/group_C_train" \
  --device cuda --seed 42 --epochs 10 --batch-size 16 --learning-rate 2e-4
```

训练保留 epoch 0，并按每轮完整最终 R 选择 `best.pt`。如训练进程中断，本版为避免
混入非完整轮次，不在原目录原地续训；保留旧目录，使用相同缓存新建训练目录重跑。

### 5. 汇总

```bash
python -u -m baselines.B5_final.g120_c3 summarize \
  --run "$run" --output "$run/comparison"
```

重点查看：

```text
$run/comparison/summary.md
$run/comparison/summary.csv
$run/comparison/summary.json
$run/group_C_train/best.pt
$run/group_C_train/completed.json
```

只有 C 组的最终 R 同时高于 A、B，才把“G120 上重新训练 C3”作为 B5-1022 候选。
B 比 A 低并不证明 C3 方法无效，只说明旧 C3 对新基础预测迁移失败。
