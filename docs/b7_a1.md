# A1：同一个P，华为真实10秒适配、10秒完整输出、拼回120秒评分

独立分支`B7-A1`基于`B7-M4-M5`的`571976a`。不在活动的B7/U7/B7-T目录切换分支。

## 训练和评估定义

```text
对应模型已完成的P
    ├─→ A：40秒华为适配（原实验，继续保留）
    └─→ A1：10秒华为适配（新输出目录）
```

A1不重新公开预训练、不从已经微调过的A或Q/B继续、不转换U7/Transformer权重。
从选定P的EMA初始化同一网络，新建AdamW和华为适配步数；模型宽度/深度/patch等均从P读取。
支持U7（原B7、M2/M3、M4/M5）及B7-T（原模型、g6_19m、w144_g5_21m）。
P必须已经有有效`completed.json`，指定`P/best_r.pt`，不能拿正在训练P的临时best开始。

默认1000次参数更新、batch32、lr1e-5、AdamW weight_decay=.01、EMA=.999、梯度裁剪1、seed42。
每500步保存last；没有初始/中途全量验证，只在1000步末尾评估最终EMA。
`best_r.pt`/`best.pt`在A1只代表末步EMA，不从中间多个权重挑点。
中途停止后重跑同一命令，严格恢复模型、优化器、EMA、随机状态和步数；末尾验证中断会补完。
更换物理GPU编号允许，其他代码/配置/P来源/数据变化仍会拒绝续训。

华为原始缓存保持整条120秒，训练随机取真实10秒；不同训练窗口可以重叠。
I完整波形直连且不加噪；七通道状态/速度为II、V1–V6；FM、MAE、PCC都计算完整真实10秒。
不使用40秒的15–25秒裁剪；10秒核心就是整段10秒。II权重5和父P的loss设置沿用。
I复制、四条肢体导联公式重建及固定尺度保持不变。

推理：0–10、10–20、……110–120秒共12个输入；每段完整生成10秒，K16平均后顺序拼接。
没有输入上下文重叠、没有额外边缘补齐、没有相邻段融合或交叉平均。
只在每段内部做K16平均。短窗输出接缝仍可能不连续，不能保证高于40秒方案。

**最终r必须在拼好的真实完整120秒上计算**，不是平均12个窗口r。
阶段明确新增`huawei10`，QC、患者/目标聚合及组权重与`huawei40`一致：
task1×0.5＋machine×0.25＋body×0.25。绝不能改名为public10绕过配置检查，否则评分会改变。
验证记录不足真实120秒会拒绝，而不是裁短后继续评分。

## 数据与实现位置

直接复用原华为manifest及NPZ、患者划分、逐导联QC、训练集尺度。不重新prepare或缓存。
入口会核验parent P已完成、数据文件存在和SHA256、尺度、完整验证记录与三分组。
新模型仍需重新生成验证波形，不能复用A的预测分数。

- U7使用本分支的`baselines.B7`，增加huawei10阶段和原华为评估分支。
- Transformer使用隔离包`baselines.B7T_A1`；它来自本地B7-T-compact的`b1a4e23`，
  模型/flow/loss/inference保持该版本实现，训练配置和评估补huawei10，不修改原T工作树。
- 自动根据architecture_id选择后端；model config直接来自P，strict加载EMA，无结构转换。
- P/原A/Q/B检查点只读。A1新checkpoint使用新代码身份；不要拿它续训原A，后续评估使用本分支。

入口每次管理一个A1训练进程。不同模型各用不同output；同一output有进程锁，重复启动会拒绝。
可在一个tmux中开多个窗口分别训练，但不会自动控制其他窗口/旧实验的GPU占用。
以下GPU0仅为示例，按空闲资源选择，不必暂停仍运行的A/Q/B来增加A1。

### 已知路径示例：U7 M2 A1

```bash
conda activate BioFlow
cd /home/qht/huawei_B7_A1
mkdir -p results/A1/M2
set -o pipefail
python -u scripts/run_b7_a1.py \
  --parent-checkpoint /home/qht/huawei_B7_U7_large/results/B7-M2-M3_gpu2/M2_seed42/P/best_r.pt \
  --manifest /home/qht/huawei_B7/results/B7/auto_seed42/data/huawei/manifest.json \
  --output results/A1/M2 --gpu 0 \
  2>&1 | tee -a results/A1/M2/run.log
```

M3将parent路径中的M2_seed42替换为M3_seed42，并将output改为results/A1/M3。
原B7可用`/home/qht/huawei_B7/results/B7/batch32_finalval_seed42/P/best_r.pt`，另起output。

### B7-T及两组新T

先在各自实验目录找到**已完成的P**。实际结果目录以服务器为准，不假定新的T输出根路径：

```bash
find /home/qht/huawei_B7_T* -type f -path '*/P/best_r.pt'
```

将准确路径填入同一个入口，输出目录分开，例如原T用results/A1/T_original、
g6用results/A1/T_g6、w144用results/A1/T_w144。

```bash
python -u scripts/run_b7_a1.py \
  --parent-checkpoint /实际实验目录/P/best_r.pt \
  --manifest /home/qht/huawei_B7/results/B7/auto_seed42/data/huawei/manifest.json \
  --output results/A1/T_original --gpu 0
```

`--dry-run`读取检查点/缓存信息、打印自动生成的A1配置，不创建训练目录、不使用GPU。
默认训练参数无需另配JSON；第一次运行会生成output/config.json、a1_spec.json和train/。
调整步数/batch/lr属于新实验，使用新的output；不要编辑进行中实验的config.json。

## 进度与续训

```bash
tail -n 10 -f /home/qht/huawei_B7_A1/results/A1/M2/run.log
cat /home/qht/huawei_B7_A1/results/A1/M2/train/completed.json
```

出现`[A1] backend=...`和训练步数递增表示启动；`[DONE]`表示训练及末尾验证成功。
completed.json在结束后才存在。历史r记录在train/history.jsonl；完整记录验证报告在
train/validation_0001000.json；最终权重train/best_r.pt，恢复点train/last.pt。
停止后重新执行完全相同命令，自动恢复；允许仅改`--gpu`迁卡。
失败首步仅留下initial时，核验身份后从真实第0步恢复，保留initial原件。
不自动启动其他模型的A1，也不自动启动A/Q/B；原训练路线不受影响。

对比A与A1时记下两者1000步×batch32下，40秒A处理的信号时长是10秒A1的4倍。
当前优先快速探索短窗是否改善R，不应把差异全部解释为某一单独因素。
