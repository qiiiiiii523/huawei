# B7-U7逐层结构

日期：2026-10-24。状态：已在`baselines/B7/model.py`独立实现，随机初始化，不继承B5权重。U-Net通道与块排列沿用已讨论的结构选择；代码不导入B5模块。

## 1. 输入与输出合同

固定生成顺序：`J=(II,V1,V2,V3,V4,V5,V6)`。

| 张量 | 形状 | 意义 |
|---|---|---|
| q | [B,1,T] | 以固定scale归一化的当前同步I，不加生成噪声 |
| x_t | [B,7,T] | 七个未知导联在生成时间t的状态 |
| u_t=concat(q,x_t) | [B,8,T] | 波形主干直接输入 |
| t | [B] | 0到1的生成时间，不是ECG物理时间 |
| metadata | numeric[B,3]、sex[B]等 | 年龄/身高/体重、性别与合法缺失标记 |
| v_theta | [B,7,T] | 七个生成导联的速度，不是I重建结果 |

500Hz下：10秒T=5000，40秒T=20000。当前I不做条件dropout、不做随机遮挡，不放进flow路径。时间与人口学条件保持可编码。

## 2. 主干

```text
q: 干净I ──────┐
x_t: 七个状态 ──┴─ concat → stem8→64 → E0 ────────────── S0
                                      ↓ down1
                                    E1 ────────── S1
                                      ↓ down2
                           bottleneck (d=1,2,4,8)
                                      ↓ up1
                                concat(S1) → D1
                                      ↓ up0
                                concat(S0) → D0
                                      ↓ head64→7
                                    v_theta
```

以下输出形状保留batch维。卷积默认有bias；同分辨率核3卷积按膨胀率padding以保持长度，卷积核7用padding3；下采样核4、stride2、padding1。

| 阶段 | 运算 | 40秒形状 |
|---|---|---|
| 输入 | concat(I,x_t)，顺序固定I、II、V1～V6 | [B,8,20000] |
| stem | Conv1d 8→64，kernel7，stride1 | [B,64,20000] |
| E0 | 2个64通道条件残差块，d=1；保存S0 | [B,64,20000] |
| down1 | Conv1d 64→128，kernel4，stride2 | [B,128,10000] |
| E1 | 2个128通道条件残差块，d=1；保存S1 | [B,128,10000] |
| down2 | Conv1d 128→256，kernel4，stride2 | [B,256,5000] |
| bottleneck | 4个256通道残差块，d依次1、2、4、8 | [B,256,5000] |
| up1 | nearest插值至S1长度，Conv1d 256→128，kernel3 | [B,128,10000] |
| merge1 | concat上采样与S1，256→128的1×1卷积 | [B,128,10000] |
| D1 | 2个128通道残差块，d=1 | [B,128,10000] |
| up0 | nearest插值至S0长度，Conv1d 128→64，kernel3 | [B,64,20000] |
| merge0 | concat上采样与S0，128→64的1×1卷积 | [B,64,20000] |
| D0 | 2个64通道残差块，d=1 | [B,64,20000] |
| 输出头 | Conv1d 64→7，kernel1 | [B,7,20000] |

共12个残差块。10秒的时间轴为5000→2500→1250→2500→5000，使用同一套参数。U7不含Transformer；UT7/T7见整体方案，不能混称为已实现的U7。

## 3. 残差块与条件

```text
h ──────────────────────────────────────────────────┐
↓ GroupNorm(8组)                                    │
↓ SiLU                                             │
↓ Conv1d(C,C,3,padding=d,dilation=d)                 │
↓ 加Linear_C(时间嵌入)并广播到时间轴                 │
↓ GroupNorm(8组)                                    │
↓ FiLM(人口学嵌入)：(1+gamma)*feature+beta            │
↓ SiLU                                             │
↓ Conv1d(C,C,3,padding=d,dilation=d)                 │
└──────────────────── 与h相加 ←─────────────────────┘
```

时间路径：t→128维正弦余弦嵌入→MLP(128→512→128)，每残差块线性投影到自身通道。

人口学路径：年龄/身高/体重3值、性别8维embedding、4个字段有效标记、1个高龄标记，共16维，MLP(16→128→128)。每残差块用线性投影生成gamma/beta。字段缺失显式编码；当前实现无I或人口学随机dropout。

删除原 `anchor_full/anchor_half/anchor_quarter` 独立I支路、`condition_enc/condition_dec` 加法注入及 `anchor_head`。I从stem直接进入共享主干，不另训练I预测头；下采样后仍为特征表示，不宣称网络绝对无信息损失。

## 4. Flow与损失

只为J生成七通道高斯z。训练x_t=(1-t)z+t*y_J，速度目标为y_J-z；q对所有t相同。辅助波形估计为x_t+(1-t)*v_theta。

总目标为FM速度MSE + lambda_M×整窗MAE + lambda_r×PCC。40秒PCC只取[15,25)，FM/MAE使用所有真实有效位置。公开10秒PCC使用真实完整10秒。

首轮导联权重(5,1,1,1,1,1,1)作用于三项，按有效权重归一化。I无生成损失，派生四条导联不重复计入。默认lambda_M=1、lambda_r=0.1，目标方差阈值1e-8，已写入配置；这些是初始设置，尚未验证最优。

## 5. 采样、拼接与十二导联

七通道z用Heun16积分；每次速度场调用拼接同一个q。K16份生成逐点平均后，每40秒保留中央10秒，以10秒步长拼好120秒。首尾重复端点延拓，人工监督位置排除。

I直接保留观测值，七条生成波形还原为μV后计算：

```text
III = II-I
aVR = -(I+II)/2
aVL = I-II/2
aVF = II-I/2
```

最终排序I、II、III、aVR、aVL、aVF、V1～V6。II和胸导联联合生成，不先生成II再用其作为胸导联条件。隐藏真实II仅作训练标签，不作为推理条件。

完整120秒、11条缺失导联的既定验证R选best_r；评估不将II乘5。U7参数初始化策略见[独立初始化](b7_initialization.md)，完整实验顺序见[整体方案](b7_plan.md)。
