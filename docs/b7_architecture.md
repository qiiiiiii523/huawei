# B7-T：一维多尺度时序 Transformer

2026-10-24。从B7提交`1615b21`建立独立`B7-T`分支，仅替换速度场骨干及其配置/加载标识。模块入口仍为`baselines.B7`，原B7分支保持U7。当前参数量15,063,342；未进行真实ECG训练。

## 输入与输出

`I[B,1,T]`与`x_t[B,7,T]`直接拼接为`[B,8,T]`，顺序I、II、V1～V6。I为完整同步观测波形，经原有固定scale归一化，不加噪、不做ODE更新、不经过独立I编码器。七个未知通道联合生成。

Transformer的共享patch映射在拼接后进行：每10个连续采样点（500Hz时20毫秒）包含8×10=80个数，按时间、通道顺序完整展开，再Linear(80,128)。不抽取每段的单个代表值、不做平均池化，不提前丢弃I采样点。所有主干都需要特征变换，此处不宣称学习后的表示绝对无损。

## 主干

```text
完整I + 七通道状态 [B,8,T]
        ↓ 联合分片10点、Linear、正弦位置编码
局部Transformer E0 ───────────────────── S0
        ↓ 相邻token合并
局部Transformer E1 ──────────── S1
        ↓ 相邻token合并
全局Transformer ×4（覆盖整个输入窗）
        ↓ Linear扩展 + S1跳连
局部Transformer D1
        ↓ Linear扩展 + S0跳连
局部Transformer D0
        ↓ LayerNorm + Linear(128,70)
逐片恢复10点×7通道 → 完整[B,7,T]速度
```

| 阶段 | 注意力/操作 | 40秒token形状 | 10秒token形状 |
|---|---|---|---|
| 共享patch入口 | 10点联合分片，80→128 | [B,2000,128] | [B,500,128] |
| E0 | 2块，4头，窗口64，交替平移0/32 | [B,2000,128] | [B,500,128] |
| merge1 | 相邻token拼接、LN、Linear256→256 | [B,1000,256] | [B,250,256] |
| E1 | 2块，8头，窗口64，平移0/32 | [B,1000,256] | [B,250,256] |
| merge2 | 相邻token拼接、LN、Linear512→384 | [B,500,384] | [B,125,384] |
| 全局瓶颈 | 4块，12头，完整双向注意力 | [B,500,384] | [B,125,384] |
| expand1+S1 | Linear384→512，拆分token，跳连融合 | [B,1000,256] | [B,250,256] |
| D1 | 2块，8头，窗口64，平移0/32 | [B,1000,256] | [B,250,256] |
| expand0+S0 | Linear256→256，拆分token，跳连融合 | [B,2000,128] | [B,500,128] |
| D0 | 2块，4头，窗口64，平移0/32 | [B,2000,128] | [B,500,128] |
| 输出 | LN、Linear128→70、恢复原时间顺序 | [B,7,20000] | [B,7,5000] |

总计12个Transformer块，无Conv1d骨干或CNN分支。细层窗口覆盖约1.28秒，中层窗口覆盖约2.56秒；窗口平移使相邻局部区域交流。全局层可关联整个40秒，有利于探索跨心搏/长距离形态信息；这是设计动机，不是已验证的性能提升。

移位用左侧padding后分窗，不循环roll，因此不会把记录末尾当作开头的局部邻居。窗口padding的key显式屏蔽，全空窗口保持有限且输出为0；两次token合并遇奇数长度也保留有效性。标准10/40秒不存在原始采样点补齐，内部局部窗口的token补齐不产生新监督标签。输出头逐片恢复每一个采样点，不将窗口缩成token级预测或10秒输出。

最大全局注意力矩阵为500×500/头，不在20000个原始点上做全局注意力。局部层为O(N×64)，全局瓶颈仍为O((N/4)^2)，不声称全模型对任意长度具有线性复杂度。

## 条件与位置信息

保留B7时间128维MLP及人口学128维编码器的输入规则，二者拼接后进入每个Transformer块，产生两组LayerNorm的shift/scale。块采用Pre-LN、注意力残差和GELU MLP残差；MLP宽度4倍，无attention dropout或随机深度。I始终为波形通道，不转为单个条件向量。

细层采用随长度生成的正弦位置编码，局部注意力叠加可学习相对位置偏置；没有固定10秒长度的可学习位置表，所以同一模型可以从真实10秒预训练转到40秒。全局层为双向注意力，因为任务本来就允许一次输入完整窗口。

## 完整保留的B7规则

- 仅七维flow：II、V1～V6；复制I，在μV下恢复III、aVR、aVL、aVF。
- 长窗40秒输入、40秒输出；整窗有效点FM/MAE；PCC只算15～25秒。公开10秒仍为真实10秒。
- FM + 1.0×MAE + 0.1×PCC；II训练权重5，胸导联1，按有效权重归一化；评估II不乘5。
- 固定scale、患者划分、QC、华为同步目标I来源、数据准备入口均不变。
- EMA、Heun16、K16波形平均、中央10秒拼完整120秒、原评分规则选best.pt/best_r.pt。
- 优化器、学习率、预算、batch、seed、边界概率与B7对应配置一致；没有为了Transformer另调超参。

## 架构来源与实验边界

参考[Swin Transformer](https://arxiv.org/abs/2103.14030)的局部/平移窗口思想，及[DiT](https://arxiv.org/abs/2212.09748)的生成时间条件与自适应归一化思路，改为一维完整波形的velocity field。这里是项目内实现的时序变体，不是原论文官方Swin或DiT，也没有将FM训练目标改为扩散目标。

B7-T必须重新进行公开预训练，原U7权重不可直接使用。B7数据缓存和冻结scale在协议一致时可以复用；后续P_T→A_T，P_T→Q_T→B_T流程不变。初始超参尚未针对真实训练优化，不保证优于U7。测试见[b7_t_validation.md](b7_t_validation.md)。


## 复核后保留的实验判断

2026-10-24再次检查：未发现分片/恢复时间轴颠倒、局部首尾误连接、padding参与有效key、批内患者混合或全局路径未生效的问题。功能测试证明的是实现与信息通路，不证明训练效果。

非重叠10点patch的输出没有额外连续性约束，真实生成后要查看patch边界和QRS细节；10秒预训练只能提供起点，40秒适配仍须实际训练，不能因位置编码支持变长就认为长窗效果已验证。当前学习率、步数和batch严格沿用B7，适合控制规则的首轮比较，参数量与计算量并不等同于U7。尚未进行服务器GPU的完整K16评估。
