# B7-U7：M2/M3两组结构实验

本方案替代原152/304/608宽度的batch32/64实验。入口为
`scripts/run_b7_structures.py`；旧`run_b7_large.py`命令也已转到此新入口。
旧配置目录仅保留历史记录，默认B7小模型配置不变。

| 实验 | 通道宽度 | 瓶颈dilation，每个值一个残差块 | 参数量 |
|---|---|---|---:|
| M2 | 112/224/448 | 1/2/4/8/16/32 | 11,477,663 |
| M3 | 128/256/512 | 1/2/4/8 | 11,136,927 |

两组独立随机初始化P，不继承B5、小U7或另一组模型。每组执行P→A、P→Q→B。
两组都沿用干净完整I直接拼接七通道状态、七通道生成、40秒输入输出、中央15–25秒PCC、
整窗有效区FM/MAE、II训练权重5。最终评估不额外放大II权重。

| 阶段 | 数据 | batch | 更新数 | 学习率 | 全量验证 |
|---|---|---:|---:|---:|---|
| P | PTB-XL+Chapman，真实10秒 | 64 | 10000 | 1e-4 | 结束一次 |
| Q | PTBDB，40秒 | 32 | 1000 | 1e-5 | 结束一次 |
| A、B | 华为，40秒，各自独立训练 | 32 | 各1000 | 1e-5 | 各结束一次 |

AdamW、EMA衰减0.999、梯度裁剪1不变。P相比旧batch32相同步数会处理两倍窗口条次，
不能把提升完全归因于架构。新两组之间训练预算一致。

不做初始和中间全量验证；每阶段只评估最终EMA，K16、Heun16步不变，记录batch4、
ODE chunk16。`best_r.pt`和`best.pt`在本方案中均代表末步EMA，供下游加载；没有中途择优。
每500步保存`last.pt`，最终验证前也先保存。验证中断后会补完该次验证，不会误标完成。
训练loss和更新进度仍打印，停止后从最近已保存的checkpoint恢复。

## 数据缓存

直接复用旧`auto_seed42`的`data/public10`、`data/huawei`及优先选择
`ptb_recovery/data`（否则`data/ptb40`）。训练和验证划分、训练集拟合尺度、QC沿用。
不重新prepare、不复制缓存、不改变原始数据。启动时检查manifest/文件存在/尺度；训练和完成
检查仍读取缓存文件hash以保护数据身份，这会产生磁盘读取，属于核验而不是重新缓存。
旧模型验证预测/分数不能复用于新结构，阶段末仍需重新推理评估。

## GPU排程与启动

一个总控管理八个训练阶段，`--max-train 2`限制的是整个新套件，包含验证在内。
默认直接启动训练，不做GPU短测、不按空闲显存调整并发，也没有40 GiB停止限制。
超过40 GiB可以继续训练；真实CUDA OOM仍会使该训练阶段失败并记录日志，独立路线继续。
其他总控不受本套件并发限制。需要串行时手动指定`--max-train 1`。
可选`--gpu-probe`恢复启动短测与自动并发估算，默认也不限制短测峰值；
只有显式提供`--max-peak-gib`才设置短测显存预算。

将分支推送到gitee并在服务器独立checkout中拉取后，在新tmux窗口运行：

```bash
conda activate BioFlow
cd /home/qht/huawei_B7_U7_large
mkdir -p results/B7-M2-M3
set -o pipefail
python -u scripts/run_b7_structures.py \
  --reuse-data-from /home/qht/huawei_B7/results/B7/auto_seed42 \
  --output results/B7-M2-M3 --gpu 0 --max-train 2 \
  2>&1 | tee -a results/B7-M2-M3/launcher.log
```

目录以实际独立checkout为准。默认原始数据`/home/qht/huawei/data`、metadata
`/home/qht/huawei/metadata`、PTB`/home/qht/huawei/data/PTB-Diagnostic`。
仅打印命令可加`--dry-run`，不读取GPU、不准备数据、不训练。

套件输出`pipeline_status.json`、`gpu_plan.json`和`logs/M2_P.log`等独立日志；
权重分别在`M2_seed42/P`、`M2_seed42/A`等目录。
P失败只阻止该组下游；A失败不阻止Q→B，Q失败阻止该组B；另一组继续。
停止总控后用相同命令重启，会核验身份并跳过完成阶段/恢复未完成阶段，默认不做GPU短测。
不要在任务运行时拉取修改代码，不要使用原小U7训练输出目录。

```bash
cat /home/qht/huawei_B7_U7_large/results/B7-M2-M3/pipeline_status.json
tail -n 30 -f /home/qht/huawei_B7_U7_large/results/B7-M2-M3/logs/M2_P.log
```

最终比较A/B固定华为验证集评分。测试集不参与配置选择。当前仅CPU验证，真实CUDA峰值
尚未实测；没有新模型的性能结果。
